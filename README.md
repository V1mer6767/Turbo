# TURBO — 3D гонки

Браузерна 3D-гра на Three.js для телефона (PWA): 4 траси з рельєфом (ліс, пустеля на заході, сніг, ніч), 6 машин на трасі, дрифт, нітро, гараж із 4 машинами та кольорами, рекорди й монети. Усе локально, працює офлайн.

Керування: ◀ ▶ кермо, СТОП — гальмо/задній хід, ДРИФТ — ручник, НІТРО — прискорення. Газ автоматичний (можна вимкнути в налаштуваннях). На ПК: стрілки/WASD, пробіл — дрифт, Shift — нітро, C — камера, Esc — пауза.
